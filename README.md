# TravelBloom - Travel Recommendation Website

A simple travel recommendation website built with HTML, CSS and JavaScript. Search for beaches, temples or countries and get recommendations with images and descriptions.

## Live Website
https://Rimsha247.github.io/travel-recommendation/

## Features
- Home, About Us and Contact Us pages
- Navigation bar with a search bar, Search button and Clear button
- Keyword search: "beach", "temple", "country", or a country name (for example Japan)
- Results show an image, name and description
- Local time shown for country recommendations
- Contact form that opens the visitor's email app

## Pages
- `index.html` - Home page with introduction
- `about.html` - Company information and guidance for team members
- `contact.html` - Contact information and email form

## Technologies
HTML5, CSS3, JavaScript (Fetch API), JSON

## How to Run
Open the folder in VS Code and use the Live Server extension, or run:

    npx serve

Then open the link shown in the terminal.
